Version 0.1.0 research scaffold. Open this folder as an Obsidian vault, then open `docs/QVEX_Master_Index.md` to browse the linked knowledge graph.

## Python
Requires Python 3.10+ and NumPy. Install with `python -m pip install -e .`; execute tests with `python -m pytest`.

The code is a computational research scaffold, not a validated physical engine. Interpret theoretical constructs and plots as hypotheses/model outputs, not established experimental results. Review `docs/02_Open_Calibration_Checklist.md` before making empirical claims.
